# Starter: Next.js + TypeScript

Production-grade Server-Side Rendered (SSR) and Static Site Generated (SSG) web application using Next.js App Router and strict TypeScript.

---

## 📐 Architecture & Feature Ownership

```text
src/
├── app/                        # Next.js App Router root
│   ├── layout.tsx              # Root Server Component layout
│   ├── page.tsx                # Home landing page
│   ├── error.tsx               # Route segment error boundary
│   ├── not-found.tsx           # 404 handler
│   └── (dashboard)/            # Route group for authenticated views
├── assets/                     # Design tokens & CSS styles
│   └── styles/main.css
├── components/
│   ├── ui/                     # Internal UI Primitive System
│   │   ├── Alert.tsx, Badge.tsx, Button.tsx, ConfirmDialog.tsx,
│   │   ├── EmptyState.tsx, ErrorState.tsx, FormField.tsx, Input.tsx, Modal.tsx,
│   │   ├── Pagination.tsx, Select.tsx, Skeleton.tsx, Toast.tsx
│   └── shared/                 # Truly shared domain-agnostic layout elements
├── features/                   # Modular feature domains
│   ├── auth/                   # Authentication & Session Management
│   ├── management/             # Users & Permissions Management
│   ├── products/               # Golden Reference Feature
│   └── public/                 # Marketing Pages
├── hooks/                      # Typed client hooks
├── lib/                        # API client, database connectors, utilities
├── types/                      # Domain & Next.js typings
└── utils/                      # Pure formatters
```

---

## ⚡ Core Dependencies & Justification
- **Next.js (`>=14.2.0`), React (`18.3.1`) & TypeScript (`5.5.4`)**: Type-safe React server framework.
- **TanStack Query (`5.56.2`)**: Client-side server state management and query caching.
- **React Hook Form (`7.53.0`) & Zod (`3.23.8`)**: Type-safe form handling with schema validation.

---

## 🚀 Available Scripts

```bash
# Start local Next.js development server
npm run dev

# Run TypeScript type check
npm run typecheck

# Run ESLint validation (0 warnings allowed)
npm run lint

# Run automated tests
npm run test

# Build production bundle
npm run build

# Start production server
npm start
```
